Guía de Git y GitHub

Aprende los comandos esenciales de Git

¿Qué es Git?

Git es un sistema de control de versiones que permite registrar cambios en un proyecto.

¿Qué es GitHub?

GitHub es una plataforma que permite almacenar y compartir repositorios Git.

Comandos básicos de Git

  • git init - Inicializar repositorio
  • git add . - Agregar archivos
  • git commit - Guardar cambios
  • git status - Ver estado
  • git push - Subir cambios
